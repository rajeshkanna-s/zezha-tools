# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **Zezha Tools**, please **do not open a public GitHub issue**.

Instead, please report it privately via GitHub's **Security Advisories** (*Security* tab → *Report a vulnerability* on `rajeshkanna-s/zezha-tools`) with:

- A clear description of the issue and affected file/tool.
- Steps to reproduce or proof of concept.
- Potential impact and any suggested remediation.

We will review reports promptly and work on a fix before any public disclosure.

## Scope Notes

- Most calculators, document converters, and developer tools run locally in the user's browser.
- Never include real API keys, tokens, or credentials in issues or pull requests.
